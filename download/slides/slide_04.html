GETTING STARTED

A brand-new way in — mobile number, employee ID, OTP & fingerprint

1

Starry welcome screen — deep-navy sky, the 3Boxes HRMS logo card, tagline "Your workplace, in one place". Tap the arrow to continue.

2

Pick a tab — violet gradient header with two sign-in methods: Mobile Number or Employee ID. Both lead to the same account.

3

Mobile Number tab — country code (+91 default) + registered number → Continue → sends a 6-digit one-time code. Employee ID tab — ID/email + password, Save me, Forgot password?, Sign in.

4

Verify your number (OTP) — six code boxes, resend countdown, Change number link. The code is delivered to your registered email; tap Verify & continue.

5

Enable fingerprint / Face ID — offered after the first sign-in; the next launch opens with a biometric prompt instead of the keyboard.

mark_email_unread
OTP tips

Code lands in the email registered in HRMS — check spam, then tap Resend after the countdown. Codes are single-use and expire quickly; a new request invalidates the old one.

fingerprint
Biometric unlock

Tied to the device's own fingerprint / face store — a colleague's finger simply will not open your app. On shared devices skip biometrics and sign out after use.

support_agent
New employee? Contact HR

Both tabs end with a Contact HR link for first-time users. Super admins keep the Switch Workspace tile for hopping between client workspaces.

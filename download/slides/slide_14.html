Problem Fix
APK blocked Allow 'Install unknown apps' for the browser, reopen the file; upgrades install over the old app.
Cannot sign in Verify credentials on web login; on the Mobile Number tab check the registered number; update the APK; ask HR/Admin for a reset.
OTP not received Code goes to your registered email — check spam, Resend after the countdown, or switch to the Employee ID tab.
Ticket stuck Reply in the thread with details — HR/Admin see it instantly; only HR/Admin change ticket status.
GPS punch rejected Enable app location permission, remove fake-GPS apps, retry near a window.
Data looks stale Pull to refresh; verify on web; ask HR to confirm save/release.
Notification missed Open the bell tile; check Android notification permission.
Change locked/rejected Identity fields locked by policy — contact HR/Admin; photo rejections include a reason.
Escalation Employee arrow_forward HR/Admin arrow_forward Super admin (include app version and affected account)

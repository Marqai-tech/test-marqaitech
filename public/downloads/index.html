Install on Android — pick ONE edition (or switch any time)

  1. Both editions share the same app signature and version code, so either installs right over the other (and over v1.6.x / v1.7.x / v1.8.x) — no uninstall needed
  2. Native App: full Flutter experience with the raised violet AI Assistant button centred in the bottom dock
  3. Lite App: the light WebView edition that renders your live company workspace — every web feature (including the web AI dock) appears the moment it ships
  4. Open the downloaded APK file (named with the version, e.g. …-v1.9.0.apk), allow installation from unknown sources if prompted, tap "Install" and sign in
  5. If nothing happens when you open the APK: free up at least 100 MB of storage, re-download the file, then open it again — both releases work on every phone (32-bit and 64-bit)
